# SQL — учебная практика

SQL изучался в рамках курса по тестированию ПО и дополнительно на SQL Academy.

Подтверждённый уровень практики, который можно указывать в портфолио:

- базовые запросы SELECT;
- фильтрация данных;
- сортировка;
- группировка;
- работа с несколькими таблицами через JOIN.

Дополнительно на SQL Academy пройдены материалы до оператора JOIN включительно.

## Важно

Это учебная практика. Коммерческий опыт работы с SQL не заявляется.

В портфолио не фиксируются результаты выполнения конкретных SQL-задач, если они не сохранились в исходных материалах.
