# Чек-лист: авторизация

- [ ] Форма авторизации открывается без ошибок.
- [ ] Отображается поле Email.
- [ ] Отображается поле Password.
- [ ] Отображается кнопка входа.
- [ ] Успешный вход с валидными данными работает.
- [ ] Неверный пароль обрабатывается корректно.
- [ ] Несуществующий пользователь обрабатывается корректно.
- [ ] Пустой Email валидируется.
- [ ] Пустой Password валидируется.
- [ ] Оба пустых поля валидируются.
- [ ] Некорректный формат Email обрабатывается корректно.
- [ ] Поведение Enter соответствует требованиям.
- [ ] После успешного входа открывается авторизованная зона.
- [ ] Сессия ведёт себя согласно требованиям после обновления страницы.
- [ ] Неавторизованный пользователь не получает доступ к защищённой странице.
- [ ] Ошибки не приводят к неожиданному переходу в авторизованную зону.
