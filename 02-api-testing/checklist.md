# Checklist — REST API

## Request

- [ ] HTTP method выбран корректно
- [ ] URL/endpoint указан корректно
- [ ] Path parameters передаются корректно
- [ ] Query parameters передаются корректно
- [ ] Headers соответствуют запросу
- [ ] JSON body имеет ожидаемую структуру
- [ ] Обязательные поля присутствуют

## Response

- [ ] HTTP status code соответствует сценарию
- [ ] Response body присутствует там, где ожидается
- [ ] Структура JSON соответствует контракту
- [ ] Значения ключевых полей корректны
- [ ] Ошибки возвращаются в ожидаемом формате

## Negative testing

- [ ] Невалидные значения параметров
- [ ] Отсутствующие обязательные параметры
- [ ] Некорректный идентификатор
- [ ] Некорректное значение enum/status
- [ ] Проверка соответствующего HTTP-кода ошибки

## CRUD

- [ ] Create — POST
- [ ] Read — GET
- [ ] Update — PUT
- [ ] Delete — DELETE

## Authorization

- [ ] Запрос без авторизации
- [ ] Запрос с авторизационными данными
- [ ] Проверка поведения при некорректных данных авторизации

> Чек-лист используется как учебный материал и не является отчётом о выполнении всех перечисленных проверок.
