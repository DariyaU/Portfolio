# BUG-002 — Ошибка в отчёте после обновления баз

**Тип:** Bug  
**Priority:** Low  
**Severity:** Low  
**Environment:** Windows 10, ПО 6.4.5.77, ru_RU  
**Frequency:** Every time

## Summary

После установки последнего обновления в отчёте sysinfo отображается ошибка по версиям баз данных.

## Steps to reproduce

1. Установить последнее обновление баз.
2. Запустить сервер.
3. Открыть отчёт sysinfo.

## Expected result

Отчёт отображается без ошибок по установленным обновлениям.

## Actual result

Для двух баз в отчёте отображается сообщение о том, что текущая версия базы новее устанавливаемой, хотя обновление установлено и фактическая версия соответствует версии обновления.

## Impact

Согласно исходному описанию, ошибка не влияет на работу системы.

## Workaround

Не указан.

## Evidence

В исходном баг-репорте были приложены видео и скриншот. Они не публикуются в текущем виде.
