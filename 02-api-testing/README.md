# API testing — учебный проект

## Цель

Учебная практика ручного тестирования REST API в Postman на основе Swagger Petstore и отдельной коллекции User.

## Что отрабатывалось

- HTTP-методы GET, POST, PUT, DELETE;
- path parameters и query parameters;
- JSON request body;
- проверка HTTP status codes;
- позитивные и негативные сценарии;
- CRUD-сценарии для сущности Pet;
- передача данных пользователя через JSON и query parameters;
- базовые проверки авторизации;
- использование переменных коллекции в запросах.

## Источник практики

Материалы основаны на сохранённых учебных коллекциях Postman. Это **учебный опыт**, а не коммерческое API-тестирование.

## Структура

- `test-cases.md` — выделенные из учебных запросов тестовые сценарии;
- `checklist.md` — чек-лист ручной проверки REST API;
- `postman/README.md` — описание коллекций и типов запросов;
- `bug-reports/` — место для дефектов только при наличии подтверждённого результата выполнения.

## Ограничения

В портфолио не заявляются результаты выполнения запросов, которых нет в исходных коллекциях, и не создаются вымышленные API-дефекты.
