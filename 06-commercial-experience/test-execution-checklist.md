# Чек-лист подготовки и проведения тестирования

**Контекст:** функция «ДП» в корпоративном ПО.

## Подготовка

- [ ] Изучить требования / описание функционала.
- [ ] Подготовить тестовые данные.
- [ ] Настроить тестовое окружение.
- [ ] Проверить доступность системы.
- [ ] Создать или выбрать тест-кейсы.
- [ ] Проверить отсутствие блокирующих дефектов.

## Выполнение тестов

- [ ] Выполнить проверки пошагово.
- [ ] Сравнить фактический и ожидаемый результат.
- [ ] Зафиксировать отклонения.
- [ ] При дефекте сохранить скриншот/видео.
- [ ] Зафиксировать шаги воспроизведения.
- [ ] Указать окружение и версию продукта.
- [ ] Добавить необходимые метки и комментарии.
- [ ] Обновить статусы тестов.

## Работа с дефектами

- [ ] Описать проблему объективно и воспроизводимо.
- [ ] Указать expected / actual result.
- [ ] Приложить необходимые доказательства.
- [ ] Указать severity и priority согласно процессу.
- [ ] Проверить возможный дубликат.
- [ ] Передать дефект разработчику в ASVO.

## После тестирования

- [ ] Зафиксировать результаты выполнения.
- [ ] Обновить статус в трекере.
- [ ] Документировать известные обходные пути.
- [ ] Сохранить необходимые тестовые данные.
- [ ] Провести анализ обнаруженных проблем и результатов.

> Чек-лист переработан из рабочего материала. В публичную версию не включены внутренние идентификаторы, клиентские данные и служебные вложения.
