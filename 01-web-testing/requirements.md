# Требования

## Учебный модуль: авторизация

Пользователь должен иметь возможность войти в систему по email и паролю.

### Функциональные требования

1. На странице авторизации отображаются поля `Email` и `Password` и кнопка входа.
2. Пользователь с корректными учётными данными может войти в систему.
3. При неверных данных пользователь получает понятное сообщение об ошибке.
4. Пустые обязательные поля не позволяют выполнить успешную авторизацию.
5. После успешного входа пользователь попадает на главную страницу авторизованной зоны.
6. Сессия пользователя сохраняется после успешного входа.

### Вопросы к требованиям

- Какие ограничения действуют для длины email и пароля?
- Допускаются ли пробелы в начале и конце email?
- Какой точный текст сообщения показывается при неверном пароле?
- Есть ли ограничение количества неуспешных попыток?
- Должна ли работать авторизация по Enter?
- Как ведёт себя форма при недоступности сервера?
