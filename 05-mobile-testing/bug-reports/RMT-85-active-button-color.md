# RMT-85 — Цвет активной кнопки не соответствует макету

**Тип:** UI / Visual testing  
**Проект:** «ПО Ремонт» Android MVP  
**Платформа:** Android, физическое устройство  
**Severity:** Minor  
**Priority:** Medium

## Контекст

При проверке соответствия реализованного интерфейса макетам Figma обнаружено систематическое расхождение в цвете активных кнопок.

В макете активная кнопка выполнена в сине-фиолетовой гамме, а в проверенной сборке на экранах приложения отображалась зелёной.

## Предусловия

- приложение «ПО Ремонт» запущено;
- открыт экран, содержащий активную основную кнопку.

## Шаги воспроизведения

1. Открыть экран с активной основной кнопкой.
2. Зафиксировать цвет кнопки в приложении.
3. Сравнить реализацию с соответствующим экраном в Figma.
4. Повторить проверку на других экранах с основной кнопкой.

## Фактический результат

На проверенных экранах активная кнопка отображалась зелёным цветом.

## Ожидаемый результат

Цвет активной кнопки должен соответствовать утверждённому макету — сине-фиолетовая гамма.

## Почему это важно

Дефект не блокирует пользовательский сценарий, но нарушает визуальную консистентность продукта и соответствие реализации согласованному дизайну. Для QA это также сигнал проверить, является ли причина локальной для одного экрана или связана с общим стилем компонента.

## Что было сделано QA

- реализация сравнена с макетом Figma;
- расхождение подтверждено на нескольких экранах;
- зафиксированы actual и expected result;
- дефект классифицирован как Minor / Medium;
- приложено визуальное подтверждение.
