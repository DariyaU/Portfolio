# Postman — учебные коллекции

В проекте использовались сохранённые учебные коллекции Postman.

## Swagger Petstore

Практика включает запросы к сущности `Pet` и сценарии с:

- GET — получение данных;
- POST — создание ресурса;
- PUT — обновление ресурса;
- DELETE — удаление ресурса;
- path/query parameters;
- JSON request body;
- позитивными и негативными входными данными;
- проверкой HTTP status codes;
- отдельными запросами, связанными с авторизацией.

## User

Отдельная коллекция содержит учебные POST-запросы для передачи данных пользователя:

- JSON request body;
- query parameters;
- проверка структуры запроса и HTTP-ответа.

## Как это отражать в резюме

Корректная формулировка: **Postman — учебная практика REST API: GET/POST/PUT/DELETE, параметры, JSON, HTTP status codes, позитивные и негативные проверки.**

Не следует формулировать это как коммерческий опыт API-тестирования.
