# BUG-001 — Не выполняется текстовый поиск

**Тип:** Bug  
**Priority:** High  
**Severity:** Critical  
**Environment:** Windows 10, NormaCS 4.1.34.548, ru_RU  
**Frequency:** Every time

## Summary

Не выполняется поиск по тексту на главной странице через интеллектуальный поиск.

## Steps to reproduce

1. Ввести в строку поиска запрос `бетонные перекрытия`.
2. Нажать кнопку «Поиск».

## Expected result

Поиск выполняется, отображается список соответствующих документов.

## Actual result

Поиск не выполняется, отображается 0 документов.

## Workaround

Не найден.

## Evidence

В исходном баг-репорте были указаны скриншот, видео и log. Файлы не публикуются в текущем виде, так как могут содержать внутренние данные.
