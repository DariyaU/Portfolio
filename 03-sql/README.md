# SQL — учебная практика

SQL изучался в рамках курса по тестированию ПО и дополнительно на SQL Academy.

Подтверждённый уровень практики, который можно указывать в портфолио:

- базовые запросы SELECT;
- фильтрация данных;
- сортировка;
- группировка;
- работа с несколькими таблицами через JOIN.
