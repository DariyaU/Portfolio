# Итоговый отчёт

## Статус

Шаблон отчёта для фиксации результатов выполнения тестов.

## Объём

Проверка авторизации по требованиям из `requirements.md`.

## Что необходимо зафиксировать после выполнения

- количество выполненных тест-кейсов;
- количество Passed / Failed / Blocked;
- найденные дефекты;
- критичность и приоритет дефектов;
- известные ограничения;
- решение о готовности функциональности к следующему этапу.
