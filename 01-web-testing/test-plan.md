# План тестирования

## Цель

Проверить, что пользователь может корректно авторизоваться и что основные негативные сценарии обрабатываются ожидаемым образом.

## Объём

- отображение формы;
- ввод данных;
- успешная авторизация;
- неверные данные;
- пустые поля;
- переход после входа;
- сохранение сессии;
- базовые негативные сценарии.

## Виды тестирования

- functional;
- negative;
- smoke;
- regression;
- exploratory.

## Не входит в объём

Нагрузочное, security и автоматизированное тестирование — в рамках этого учебного проекта не выполняются.

## Результат

Результаты фиксируются в тест-кейсах, чек-листе, баг-репортах и итоговом отчёте.
