# 06 — Коммерческий опыт тестирования

Анонимизированное описание реального опыта тестирования корпоративного ПО в рамках основной работы.

## Контекст

С 28.08.2023 работаю в ООО «НТПЦ Решение» в роли ведущего специалиста по работе с клиентами (внедрение и поддержка ПО). В работе взаимодействую с NormaCS / ИСС Техэксперт.

Тестирование является частью коммерческой деятельности в рамках этой должности: проверяю изменения продукта, обновления и интеграции перед использованием/демонстрацией, воспроизвожу дефекты и передаю их разработчикам.

## Что реально выполняю

- функциональное тестирование;
- smoke-тестирование после обновлений и установок;
- regression testing после исправлений;
- integration testing;
- exploratory testing;
- black-box testing;
- acceptance checks нового и изменённого функционала;
- retest исправлений;
- воспроизведение и локализация проблем на уровне первой линии;
- анализ логов при технической диагностике;
- оформление баг-репортов в ASVO со шагами, ожидаемым/фактическим результатом и вложениями;
- проверка поиска, динамических папок, Acrobat/PDF, Word, CAD, установки и обновления ПО;
- взаимодействие с разработчиками и технической поддержкой.

## Результаты и улучшения процесса

- Внедрила более структурированный формат описания дефектов по шаблону трекера, чтобы уменьшить количество уточняющих вопросов от разработчиков.
- Ввела smoke-проверки после ежемесячных обновлений, чтобы раньше выявлять проблемы, возникающие после установки новой версии.

## Конфиденциальность

Названия внутренних систем, версии, идентификаторы, клиентские данные, скриншоты и другие служебные материалы не публикуются. Примеры в этом разделе обезличены.

> Этот раздел основан на коммерческом опыте. Учебные навыки SQL, Postman, Swagger, DevTools и Git не выдаются за коммерческий опыт.
