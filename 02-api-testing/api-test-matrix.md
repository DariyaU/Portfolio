# API test matrix — метод → endpoint → проверка → ожидаемый результат

Матрица собрана по фактическим запросам из учебных коллекций Postman. Она показывает структуру проверок API и не утверждает, что каждый результат был фактически выполнен и подтверждён.

| Метод | Endpoint / объект | Проверка | Ожидаемый результат |
|---|---|---|---|
| GET | `/pet/findByStatus` | Валидный `status` | Успешный ответ, список питомцев |
| GET | `/pet/findByStatus` | Невалидный `status` | Корректная обработка некорректного значения |
| GET | `/pet/{petId}` | Валидный `petId` | Возвращается питомец с ожидаемыми полями |
| GET | `/pet/{petId}` | Некорректный/несуществующий `petId` | Ожидаемая ошибка API |
| POST | `/pet` | Валидный JSON body | Питомец создаётся, HTTP-ответ соответствует контракту |
| POST | `/pet` | Неполный/некорректный body | API корректно обрабатывает невалидные данные |
| PUT | `/pet` | Изменение существующего питомца | Данные обновляются, ответ соответствует контракту |
| DELETE | `/pet/{petId}` | Удаление существующего питомца | Ресурс удалён, возвращён ожидаемый HTTP-ответ |
| GET | `/pet/findByTags` | Валидный список `tags` | Возвращается результат поиска по тегам |
| GET | `/store/inventory` | Получение inventory | JSON-ответ содержит данные inventory |
| POST | `/store/order` | Валидный JSON заказа | Заказ создаётся, ответ соответствует контракту |
| GET | `/store/order/{orderId}` | Валидный `orderId` | Возвращается заказ |
| DELETE | `/store/order/{orderId}` | Удаление заказа | Заказ удаляется/операция подтверждается ожидаемым кодом |
| POST | Bugred `doregister` | JSON с данными пользователя | API обрабатывает регистрацию и возвращает HTTP-ответ |
| POST | Bugred `doregister` | Query parameters `email`, `name`, `password` | API обрабатывает переданные параметры |
| POST | Bugred `createcompany` | JSON с данными компании | API обрабатывает создание компании |
| GET | `/user/login` | Валидные параметры авторизации | Возвращается ожидаемый ответ авторизации |
| PUT | `/user/{username}` | Изменение пользователя | Данные пользователя обновляются |
| DELETE | `/user/{username}` | Удаление пользователя | Пользователь удаляется/операция подтверждается ответом |
| GET/POST | Запросы Petstore с переменными | `base_URL`, `pet_ID` и другие переменные | Переменные подставляются в запрос корректно |
| GET/POST | Запросы с Postman scripts | Tests / scripts | Скрипт выполняется при соответствующем результате запроса |

> Это учебный API-проект. Коммерческий API-тестинг не заявляется.
