# TC-001 — Успешная авторизация пользователя

**Приоритет:** High  
**Тип:** Functional / Positive

## Предусловия

- Пользователь не авторизован.
- Существует тестовая учётная запись с валидными данными.

> Реальные логины и пароли в репозитории не публикуются.

## Шаги

| # | Действие | Ожидаемый результат |
|---|---|---|
| 1 | Открыть `/login` | Отображается форма авторизации |
| 2 | Ввести валидные email и пароль | Поля заполнены корректными значениями |
| 3 | Нажать «Войти» | Пользователь авторизован и переходит на главную страницу |

## Постусловия

Пользователь находится в авторизованной зоне.

## Примечание

Исходный тест-кейс из портфолио переработан в Markdown. Тестовые credentials заменены на абстрактное описание, чтобы не хранить пароли в публичном репозитории.
