# 01 — Web testing

Учебный проект для демонстрации полного цикла ручного тестирования веб-приложения.

## Что будет показано

- анализ требований;
- тест-дизайн;
- тест-кейсы и чек-листы;
- функциональное и негативное тестирование;
- smoke и regression checks;
- оформление дефектов;
- traceability matrix;
- итоговый тестовый отчёт.



## Структура

- `requirements.md` — требования и вопросы к ним;
- `test-plan.md` — краткий план тестирования;
- `test-cases.md` — набор тест-кейсов;
- `checklist.md` — функциональный чек-лист;
- `bug-reports/` — учебные баг-репорты;
- `traceability-matrix.md` — связь требований и проверок;
- `test-summary.md` — итоговый отчёт.
