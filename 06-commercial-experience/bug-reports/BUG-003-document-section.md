# BUG-003 — Не открывается раздел «ДП» из списка документов

**Тип:** Bug  
**Priority:** Medium  
**Severity:** Medium  
**Environment:** Windows 10, ПО 4.1.34.548, ru_RU  
**Frequency:** Intermittent, примерно каждый второй цикл воспроизведения

## Summary

При нажатии кнопки «ДП» из списка документов не выполняется переход в соответствующий раздел.

## Steps to reproduce

1. Выполнить поиск документов и получить список результатов.
2. Добавить документы в «ДП».
3. Нажать кнопку «ДП» для перехода в раздел.

## Expected result

Открывается раздел «ДП».

## Actual result

Раздел не открывается.

## Workaround

Перейти в папку со стартовой страницы.

## Evidence

В исходном баг-репорте были указаны видео и скриншот. Они не публикуются в текущем виде.
